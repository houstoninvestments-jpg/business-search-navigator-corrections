# Business Search Navigator: correction reports

This repository only collects correction reports for Business Search
Navigator, an independent guide to official state business search and
filing tools.

To report a wrong, broken, or outdated link, open a new issue and choose
"Correction report."

- Reports are public. Anyone can read them.
- Do not include personal information or private business details.
- We cannot help with a specific filing. Contact the state office for that.

There is no code here.
